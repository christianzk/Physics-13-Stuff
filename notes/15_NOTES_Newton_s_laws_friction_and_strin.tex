PHYSICS 13 - NOTES
Newton's laws, friction and strings

One equation per axis, per object. Tilt the axes to run along an incline.

Gravity's components on an incline, when nothing else pushes perpendicular to it.

"Just starts to move" or "without slipping" means static friction is at its maximum, \(\mu_s N\), opposing the motion that's about to happen.

Frictionless objects tied together share one acceleration; the tension cancels inside the system.

A movable pulley hangs on two string segments, so the far end of the string moves twice as far.

LECTURE SUMMARY ADDITIONS

Drag opposes motion. Terminal speed occurs when weight equals drag, so acceleration is zero.
