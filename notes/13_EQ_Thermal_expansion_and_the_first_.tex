PHYSICS 13 - EQUATIONS
Thermal expansion and the first law

$$\Delta L = \alpha L \Delta T$$

$$pV = nRT = Nk_BT$$

$$U = \frac32 Nk_BT$$

$$\Delta U = Q_{\text{in}} - W_{\text{by}}$$

$$W_{\text{by}} = \int p dV$$

$$W_{\text{on}} = -W_{\text{by}}$$

$$W = 0\ \ (\text{constant } V)$$

$$W_{\text{by}} = p \Delta V\ \ (\text{constant } p)$$

$$\Delta U = 0$$

$$Q = W_{\text{by}} = nRT\ln\frac{V_2}{V_1}$$

$$Q = 0$$

$$\Delta U = -W_{\text{by}}$$

$$\Delta U_{\text{cycle}} = 0$$
